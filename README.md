# HR Data Analysis Dashboard

An interactive HR Analytics Dashboard developed using Power BI to analyze employee data, workforce trends, salary insights, and attrition analysis through dynamic visualizations and business intelligence reporting.

---

##  Project Workflow / Process

### 1️ Data Collection
- Imported HR dataset into Power BI
- Verified data structure and employee records

### 2️ Data Cleaning & Transformation
- Removed duplicate and null values
- Standardized columns using Power Query
- Formatted data types for accurate analysis

### 3️ Data Modeling
- Created relationships between tables
- Structured data model for better performance

### 4️  DAX Calculations
- Created calculated columns and measures
- Developed KPIs for employee and salary analysis

### 5️ Dashboard Development
- Designed interactive dashboards
- Added charts, slicers, filters, and KPI cards
- Created department-wise and employee-wise analysis

### 6️ Insights Generation
- Analyzed attrition trends and workforce distribution
- Identified salary and performance patterns
- Generated business insights for HR decision-making
